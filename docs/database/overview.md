# 数据库总览

EduKit 使用 PostgreSQL 作为核心数据库，Redis 作为缓存和队列。

## 数据库分层

| 库 | 用途 | 存储引擎 |
|----|------|----------|
| `edukit` | 主业务库 | PostgreSQL |
| 缓存层 | Session / 热点数据 / 队列 | Redis |
| 对象存储 | 教材/作业/头像等文件 | MinIO / S3 |
| (可选) OLAP | 报表分析 | ClickHouse / PG 分区表 |

## 主业务库 ER 概览

- 组织维度：学校 / 校区 / 年级 / 班级 / 教研组
- 用户维度：学生 / 教师 / 家长 / 管理员
- 教学维度：课程 / 教材 / 课表 / 作业 / 考试 / 成绩
- 行政维度：考勤 / 德育 / 财务 / 资产管理
