# 学校本地服务器架构

部署在学校机房/局域网内的单机或小型集群，**7×24 小时**稳定运行。

## 硬件要求 (单服务器推荐)

- CPU: 4 核以上
- 内存: 8 GB+
- 磁盘: 256 GB SSD+
- 网卡: 千兆 LAN

## 服务组成

- **PostgreSQL**：主数据库
- **Redis**：缓存 + 任务队列
- **Django Backend**：业务 API + 管理后台
- **Celery Worker**：异步任务 (同步/报表/通知)
- **Next.js Frontend**：教师/学生端 UI
- **Nginx**：反向代理 + 静态文件
- **备份容器**：每日快照备份
- **健康检查/监控**：(可选) Prometheus + Grafana

## 离线优先策略

- 所有核心业务完全本地运行，不依赖互联网
- 网络恢复后自动与 Cloud 端增量同步
