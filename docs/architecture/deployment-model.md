# 部署模型

EduKit 支持灵活的部署模式，根据学校规模和网络条件选择。

## 模式一：纯云端 SaaS

适用：小型学校/培训机构，网络稳定可靠。

- 所有服务部署在云端
- 学校端仅需浏览器访问
- 成本最低，运维最简单

## 模式二：纯本地部署 (Standalone)

适用：无法连接外网的学校/特殊网络环境。

- 全部服务部署在学校本地
- 不与云端同步
- 需要本地运维能力

## 模式三：云边协同 (Hybrid, 默认推荐)

适用：大多数 K12 / 中职院校。

- 学校本地部署完整业务系统
- 定期/实时向云端汇总数据
- 云端推送系统更新、下发全局配置
- 断网时本地完全可用，联网后自动同步
