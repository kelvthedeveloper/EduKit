# 云边数据同步总览

保证学校本地 (School Server) 与云端 (Cloud) 之间的数据一致性是 EduKit 的核心能力。

## 设计目标

- **网络不敏感**：网络中断不影响本地使用，恢复后自动同步
- **最终一致性**：允许短期不一致，通过异步机制收敛
- **双向同步**：
  - 云端 → 学校：系统配置、全局字典、教材资源
  - 学校 → 云端：业务数据、考勤成绩、使用日志
- **可审计**：每次同步产生完整日志，可追溯

## 核心组件

- **Sync Engine**：运行在学校端，调度同步任务
- **Sync Gateway**：云端 API，接收/下发同步批次
- **CDC (Change Data Capture)**：捕获增量变更
- **Conflict Resolver**：冲突处理策略引擎
