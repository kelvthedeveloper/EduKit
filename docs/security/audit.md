# 安全审计

系统必须满足教育行业合规要求 (《网络安全法》、等级保护 2.0 等)。

## 审计日志分类

| 类别 | 内容 | 保留期限 |
|------|------|----------|
| 登录日志 | 成功/失败、IP、UA、时间 | ≥ 180 天 |
| 操作日志 | 关键数据的增删改、操作人、前后值 | ≥ 1 年 |
| 敏感访问 | 身份证、成绩、病历等敏感字段查询 | ≥ 1 年 |
| 配置变更 | 角色权限、系统参数变更 | ≥ 3 年 |
| 同步日志 | 云边同步批次统计、异常 | ≥ 90 天 |

## 不可篡改

- 审计日志写入后禁止 UPDATE / DELETE
- 定期 Hash 上链 / 归档到对象存储
