# 授权 (Authorization)

EduKit 采用 **RBAC + 数据范围 (Data Scope)** 组合模型。

## 角色层级

```
超级管理员 (平台级)
   │
   ├─ 教育局管理员 (区域级)
   │
   └─ 学校管理员 (校级)
        ├─ 教研组长
        ├─ 年级主任
        ├─ 班主任
        ├─ 任课教师
        └─ 学生 / 家长
```

## 权限粒度

- **菜单权限**：前端菜单/页面可见性
- **按钮权限**：具体操作 (增/删/改/审)
- **字段权限**：敏感字段脱敏 (如身份证号、手机号)
- **数据范围**：
  - 全部 (教育局)
  - 本学校
  - 本年级
  - 本班级
  - 本人 (学生查看自己成绩)
